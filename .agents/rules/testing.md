# Exigencia de Pruebas Automáticas y Cobertura

- **Mantenimiento de Tests**: Ante cualquier modificación, refactorización o nueva funcionalidad, se DEBE agregar nuevas pruebas si aplica o actualizar las pruebas existentes afectadas para reflejar el comportamiento actual.
- **Ejecución Obligatoria**: Tras realizar cambios en el código, se DEBE ejecutar la suite de pruebas unitarias (`npm run test`) para verificar que no se haya introducido ninguna regresión y que todas las pruebas pasen al 100% antes de dar la tarea por completada.
